# 初期データ

01.サンプル記事.phpは、No.1〜No.30のタイトルと本文を持つ公開記事を投入するWP-CLI用スクリプトです。このフォルダはGit管理対象です。

## 再構築後の投入

作業ルートで実行します。

```bash
npm ci
npm start
npm run seed
```

.wp-env.jsonのmappingsで、このフォルダをコンテナの/var/www/html/seedへ共有しています。既存環境へ初めてこの設定を追加した場合は、npm start -- --updateで反映します。

## 再実行時の動作

- sample-post-1〜sample-post-30のスラッグで既存の投稿を確認します。
- 存在する記事はスキップし、本文・タイトル・公開状態を変更しません。
- 不足する記事だけ新規作成します。途中で失敗しても再実行できます。
- 同じスラッグを別の記事に使用すると、その番号もスキップされます。
- 初期データの内容を変更しても、投入済み記事には自動反映されません。
- 投稿IDは採番されるため、再構築前と同じ値になる保証はありません。

npm run seedの対象は開発環境です。テスト環境や既存の投稿・画像のバックアップ復元は含みません。起動時の自動投入は行わず、必要なタイミングで明示的に実行します。
